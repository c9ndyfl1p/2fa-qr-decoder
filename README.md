# 2FA QR Decoder

Небольшая программа для переноса кодов из **QR-кода экспорта Google Authenticator** в другое приложение-аутентификатор.

Она считывает один QR-код или все QR-коды из изображений в папке, показывает секретные ключи и создаёт отдельный QR-код для каждого аккаунта. Полученные QR-коды можно отсканировать новым аутентификатором. Совместимость зависит от приложения: оно должно уметь добавлять аккаунт по стандартному `otpauth://` QR-коду.

> **Важно:** секретные ключи дают возможность создавать ваши коды входа. Не отправляйте фотографии экспорта, полученные QR-коды, `otpauth_uris.txt` или вывод терминала другим людям. После переноса удалите временные файлы и очистите корзину.

## Для Mac

### 1. Скачайте программу

На этой странице нажмите зелёную кнопку **Code**, затем **Download ZIP**. Откройте скачанный архив — появится папка `2fa-qr-decoder-main`.

### 2. Установите Python

Если Python ещё не установлен, скачайте Python 3 с [официальной страницы](https://www.python.org/downloads/). Во время установки используйте стандартные настройки.

### 3. Установите нужную библиотеку

Откройте программу **Terminal** (её можно найти через поиск Spotlight: нажмите `⌘ + пробел` и введите `Terminal`). Выполните команду:

```bash
python3 -m pip install opencv-python
```

Если система предложит подтвердить действие, подтвердите. Дождитесь окончания установки.

### 4. Запустите перенос

В Terminal введите команду ниже, но пока **не нажимайте Enter**:

```bash
python3 
```

Перетащите файл `decode_auth.py` из распакованной папки в окно Terminal. Нажмите пробел, затем перетащите снимок с QR-кодом экспорта Google Authenticator и нажмите Enter.

В итоге команда будет выглядеть примерно так:

```bash
python3 /путь/к/2fa-qr-decoder-main/decode_auth.py /путь/к/снимку.jpg
```

Пути подставятся автоматически — вручную их вводить не нужно. Если экспорт содержит несколько QR-кодов, запустите программу для каждого снимка или передайте папку с изображениями вместо одного снимка.

## Для Windows

1. Скачайте архив кнопкой **Code → Download ZIP** и распакуйте его.
2. Установите Python 3 с [официального сайта](https://www.python.org/downloads/). В первом окне установки включите **Add Python to PATH**.
3. Откройте **PowerShell** и выполните:

   ```powershell
   py -m pip install opencv-python
   ```

4. Введите `py ` (с пробелом), перетащите `decode_auth.py` в окно PowerShell, допишите пробел, перетащите снимок QR-кода и нажмите Enter.

## Результат

Секретные ключи появятся в окне Terminal или PowerShell. Рядом со снимком создастся папка `authenticator_import`: внутри будут QR-коды аккаунтов и файл `otpauth_uris.txt`. В новом приложении отсканируйте каждый QR-код и проверьте, что вход работает, прежде чем удалять старый аутентификатор.

## Ограничения

- Скрипт читает QR-экспорт Google Authenticator (`otpauth-migration://`). Обычный QR-код входа или QR-код настройки одного сайта не подойдёт.
- Программа работает локально на компьютере и не отправляет изображение в интернет.
- Для запуска нужны Python 3 и библиотека OpenCV из `requirements.txt`.
